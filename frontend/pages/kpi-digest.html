📧 KPI Digest Bot

Generate Slack-style daily KPI digests with trend arrows, comparisons, and status indicators.

What this tool does: Define KPI metrics, generate Slack-style daily digests with trend arrows, day-over-day comparisons, and status indicators.
  • Define KPIs with SQL queries, units, and trend direction (up_is_good / down_is_good)
  • Generate daily digests with current values, day-over-day and week-over-week changes
  • View a Slack-formatted digest message with trend arrows and color coding
  • Compare current vs. yesterday values in a bar chart visualization

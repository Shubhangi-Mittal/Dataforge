🧹 Data Quality Monitor

Automated quality checks for your datasets — fast, visual, and actionable.

How it works: Upload a CSV or Excel dataset and DataForge will run automated quality checks including:
  • Completeness scoring — measure how complete each column is
  • Uniqueness analysis — detect duplicate values across columns
  • Outlier detection — flag statistical anomalies in numeric fields
  • Null value tracking — pinpoint missing data hotspots
  • Distribution analysis — summarize value distributions and data types

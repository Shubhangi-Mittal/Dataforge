✅ CSV Schema Validator

Validate CSV or Excel files against predefined schemas, or let DataForge auto-infer types and run checks for you.

What this tool does: Upload a CSV or Excel file and validate it against a schema definition or use auto-detection to infer column types. The validator checks for:
  • Type mismatches — columns that don't match their expected data type
  • Null / missing values — required fields left empty
  • Uniqueness violations — duplicate values in columns that should be unique
  • Missing or extra columns — structural differences from the expected schema

🔍 Log Anomaly Detector

Detect anomalies in metric data using statistical methods.

What this tool does: Ingest real metric data and detect anomalies using z-score, IQR, and moving average methods. Supports batch ingestion and real-time alerting.
  • Paste comma-separated numeric values or generate sample data with injected anomalies
  • Detect anomalies using three statistical methods: z-score, IQR, and moving average
  • Visualize time series data with anomaly points highlighted in red
  • Ingest data into named streams for ongoing monitoring and alert tracking
